## 3. 使用建议

如果你要继续补充“竞品资源”，建议按下面顺序扩展：

1. **先看官方文档结构**：确认产品核心概念、部署方式、演练对象与支持环境。  
2. **再看专题资源页**：白皮书、案例、能力矩阵、产品说明书通常在 Resources / Docs / Learn 页面。  
3. **最后再补充开源仓库与社区材料**：如果需要对比落地能力，可继续补 GitHub、官方博客、案例文章。  

## 4. 快速筛选建议

- 如果关注 **稳定性验证 / 故障演练 / 云原生可靠性**：优先看 Gremlin、Litmus、Chaos Mesh、AWS FIS、Azure Chaos Studio、Steadybit。  
- 如果关注 **红蓝对抗 / 紫队 / 攻击模拟 / BAS**：优先看 AttackIQ、SafeBreach、Picus、Cymulate、XM Cyber、VECTR。  
- 如果关注 **两者交叉场景**：可以把“故障注入 / 业务弹性”与“攻击模拟 / 暴露验证”拆成两条能力线做竞品矩阵。
